# YMM4 Sound Notifier

ゆっくりMovieMaker4 の操作に合わせて、設定した音声ファイルを鳴らすプラグインです。

## 鳴らせるタイミング

| トリガー | 鳴るタイミング | 鳴らない条件 |
| --- | --- | --- |
| 起動時 | YMM4のメイン画面が表示されたとき | — |
| 終了時 | YMM4を閉じるとき | 保存確認をキャンセルして終了をやめたとき |
| プロジェクト保存時 | 保存に成功したとき | ファイル名ダイアログのキャンセル、保存失敗、プロジェクトを開いた／新規作成したとき |
| プロジェクト保存失敗時 | 権限やファイルロックで保存に失敗したとき | — |
| 動画出力完了時 | 出力が最後まで終わったとき | キャンセル、出力失敗 |
| 動画出力失敗時 | 出力がエラーで終わったとき | キャンセル |
| 無操作が続いたとき | 手が止まった状態が指定時間続いたとき | 操作が続いている間 |

音声ファイルは**YMM4 がタイムラインに置ける形式**ならそのまま使えます。（ogg / opus / flac / wav / mp3 / m4a 等）

## 動作環境

- **YukkuriMovieMaker v4.56.0.0 以上**（Lite 版も同じ）
- 動作確認済み: v4.56.0.1 / v4.56.0.1 Lite

> [!IMPORTANT]
> v4.56.0.0 未満の YMM4 に入れると、**YMM4 自体が起動しなくなります。**  
> 先に YMM4 本体を更新してから導入してください。

## インストール手順

1. 本リポジトリのリリースページから **`YMM4SoundNotifier.ymme`** をダウンロードします。
2. ダウンロードした **`YMM4SoundNotifier.ymme`** を実行します。
3. 画面に表示される指示に従ってインストールを進めてください。
4. インストール完了後、YMM4 を起動し、プラグインとして認識されれば導入は完了です。

## 設定

YMM4の「設定」タブに **YMM4 Sound Notifier** が追加されます。

**全般**

- **全体の音量** — 各トリガーの音量に掛け合わされます

終了時は、設定した音声の長さから待ち時間を決めて、鳴り終わってから YMM4 を閉じます（上限 30 秒）。
再生中に次の音が鳴るときは、前の音を止めて鳴らし直します。

**各トリガー**

「音を鳴らす／音声ファイル／音量」と試聴ボタンがあります。**「音を鳴らす」をオンにしないと、音声ファイルを選んでも鳴りません。**
「無操作が続いたとき」だけ、検知方法・しきい値（秒）・繰り返しの設定が追加されます。

検知方法は 2 つから選べます。

- **キーボードとマウスの操作が無い** — パソコンの前から離れているかどうかで判定します。YMM4がアクティブかどうかは見ません
- **YMM4のウィンドウが非アクティブ** — 他のアプリを見ているかどうかで判定します。パソコンを操作していても鳴ります

失敗時の音は、動画出力の場合はエラー表示が出た時点で鳴ります（席を外していても気づけます）。
プロジェクト保存の場合は、ハンドラの呼び出し順の都合でエラーダイアログを閉じた直後に鳴ります。
